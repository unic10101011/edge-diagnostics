边缘接收调度器的任务调度
边缘周期上报节点状态
每1～2秒上报一次；节点状态发生明显变化时可以立即补报一次。网络状态可以1~2秒测量一次，外加状态明显变化补报，心跳携带最近一次测量结果。
{
  "edge_node_id": "edge_01",                  //边缘节点唯一编号
  "reported_at_ns": 1784784400100000000,      //这条节点状态报告的产生时间
  
  "resources": {                              //节点资源
    "logical_cpu_count": 8,                   //逻辑cpu个数，应为整数
    "cpu_utilization_percent": 50.0,          //cpu利用率
    "memory_available_mb": 6144,              //当前可用内存
    "gpu_available": true,                    //是否存在当前可使用的GPU
    "npu_available": false,                   //是否存在当前可使用的NPU
    "queue_length": 1                         //排队任务数
  },
  
  "models": [
    "model_version": "edge_v1.0",             //模型版本
    "load_status": "LOADED"                   //模型是否已加载
  ],

    "measured_at_ns": 1784784400000000000,    //网络测量时间
    "available_uplink_mbps_estimate": 85.0,   //估算的当前可用上传吞吐量，不是固定物理带宽

    "rtt_ms_p95": 12.6,                       //P95比单纯平均值更容易反映网络抖动
    "loss_rate": 0.001,                       //丢包比例
  },
  "last_task_activity_ns": 1784784400095000000//最近的一次任务活动时间
}
OFFLINE 不需要边缘主动发送，因为离线节点无法发送心跳。
调度器可以规定连续若干秒未收到心跳，就把节点标记为离线。
如果网络测量失败，不填写虚假的零值，应使用：

边缘收到原始包后的固定处理顺序：
1. 对原始高采样率包进行严格校验；
2. 将校验后的完整高采样率原始包写入环形缓存；
3. 对三路信号同步降采样；
4. 使用降采样数据进行预处理和特征提取；
5. 执行边缘模型推理；
6. 输出给调度器；
7. 将本包轻量摘要写入持久发送队列。
校验数据错误并输出给边缘（确定）
错误码：
MISSING_CHANNEL：缺少必要通道
INVALID_SAMPLE_RATE：采样率不符合要求
INVALID_SAMPLE_COUNT：数组长度错误
EMPTY_VALUES：采样数组为空
NON_FINITE_VALUE：包含 NaN 或无穷值
VALUE_OUT_OF_RANGE：数值超出允许范围
CHANNEL_DURATION_MISMATCH：不同通道覆盖的采样时长不一致
INVALID_TIMESTAMP：采集结束时间无效

2. 不包含任何高采样率 values；
3. 先写入本地持久队列，由后台线程批量发送；
4. 云端确认后才能删除本地队列记录。
