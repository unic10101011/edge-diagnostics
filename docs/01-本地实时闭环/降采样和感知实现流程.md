# 降采样和感知实现流程

本文档说明一个已经通过严格校验并完成原始缓存的数据包，如何转换为边缘模型需要的`PerceptionResult`。

```text
ValidatedRawPacket独立计算副本 + PerceptionInvocationContext
→ DownsampledPacket
→ PerceptionResult
```

本流程按单包处理。每包覆盖50 ms，不做跨包聚合。
## 一、职责边界和输入输出
### 1. 职责边界

本模块负责：
- 三路64 kHz高频信号同步降至16 kHz；
- 感知预处理、非阻断质量判断和特征计算；
- 组装完整`PerceptionResult`。

本模块不负责：
- 任务匹配、重复包和缺失包处理；
- 原始字段、单位、采样率、点数、数值范围和有限数值校验；
- 原始缓存写入、读取和淘汰；
- 边缘模型推理、包状态更新和摘要生成；
- THD、跨包特征、原始波形上传和云端复核。

上游校验失败或原始缓存写入失败时，不得调用本模块。降采样和感知模块只返回`ModuleStatus`及payload，不得读取或修改`TaskRecord`、`PacketRecord`、`ContextSlot`及其计数，包括`PacketRecord.current_stage`；`current_stage`由任务编排器在调用前设置。

### 2. 输入前提

调用降采样和感知模块前必须满足：
```text
packet_status = PROCESSING
cache_status = AVAILABLE
raw_packet_ref有效
完整ValidatedRawPacket已经写入原始环形缓存
传入数据是与缓存不共享可写数组的独立计算副本
PerceptionInvocationContext有效：
  edge_node_id为当前节点
  perception_received_at_ns已由任务编排器在调用前生成
```

输入数据规格为：
| 数据 | 采样率 | 点数 | 单位 |
|---|---:|---:|---|
| `vibration` | 64000 Hz | 3200 | `mm/s` |
| `phase_current_1_A` | 64000 Hz | 3200 | `A` |
| `phase_current_2_A` | 64000 Hz | 3200 | `A` |
| `shaft_speed_rpm` | 4000 Hz | 200 | 不设置`unit`字段 |
| `load_torque_nm` | 4000 Hz | 200 | 不设置`unit`字段 |
| `bearing_radial_load_n` | 4000 Hz | 200 | 不设置`unit`字段 |
| `bearing_module_temperature_c` | 单值 | 1 | 不设置`unit`字段 |

数据包必须保留`task_id`、`packet_id`、`sender_id`、`sequence_number`和`end_generate_timestamp_ns`。所有序列覆盖同一个50 ms窗口。
### 3. 模块调用返回
状态对象只包含：

```text
ModuleStatus
├── success: bool
└── error_code: string | null
```
成功数据通过同一次调用的`payload`承载，不属于状态对象：
| 调用 | 成功`payload` | 失败`payload` | 失败错误码 |
|---|---|---|---|
| 降采样 | 完整`DownsampledPacket` | `null` | `DOWNSAMPLING_FAILED` |
| 感知 | 完整`PerceptionResult` | `null` | `PERCEPTION_FAILED` |

成功时`success = true`、`error_code = null`；失败时`success = false`，不得返回部分`payload`。任务编排器只使用`ModuleStatus`控制流程，并在成功时把`payload`交给下一阶段。

## 二、总体处理流程
```text
原始缓存写入成功
→ [任务编排器] 生成PerceptionInvocationContext
   （读取统一时钟生成perception_received_at_ns，携带edge_node_id）
→ [任务编排器] 设置current_stage = DOWNSAMPLING
→ 调用降采样模块
→ 校验DownsampledPacket
→ [任务编排器] 设置current_stage = PERCEPTION
→ 调用感知模块
→ 16 kHz质量判断和感知预处理
→ 计算振动、电流和工况特征
→ 检查PerceptionResultDraft
→ 生成feature_generated_at_ns
→ 返回完整PerceptionResult
→ [任务编排器] 调用边缘模型
```
降采样或感知失败只终止当前包，任务编排器按照既有流程生成处理失败摘要并把当前包置为`PROCESSING_FAILED`，其他数据包继续处理。

## 三、同步降采样
### 1. 固定规格
三路高频信号使用同一组滤波系数、边界规则和抽取相位：
| 参数 | 取值 |
|---|---:|
| 输入/输出采样率 | 64000 Hz / 16000 Hz |
| 输入/输出点数 | 3200 / 800 |
| 降采样倍数 | 4 |
| FIR类型 | 线性相位Kaiser窗低通FIR |
| FIR系数数量 | 369 |
| Kaiser窗`beta` | 8.41 |
| 通带截止频率 | 7000 Hz |
| 阻带起始频率 | 8000 Hz |
| 设计截止频率 | 7500 Hz |
| 阻带设计目标/验收下限 | 85 dB / 80 dB |
| 通带波动设计目标/验收上限 | 0.05 dB / 0.1 dB |
| 直流增益 | 1 |
| 边界处理 | 镜像反射，不重复边界点 |

最终验收以实际固化系数的频率响应为准，不能只检查系数数量和`beta`。
### 2. 居中的零相位多相重采样
滤波器系数满足：

```text
h[i] = h[368-i]
D = (369-1)/2 = 184
```
对完整3200点输入的两端分别反射扩展184点：
```text
x_ext[-i] = x[i]
x_ext[N-1+i] = x[N-1-i]
i = 1...184
```
居中卷积和固定相位抽取定义为：

```text
z[n] = sum(h[r+184] × x_ext[n-r]), r = -184...184
y[m] = z[4m], m = 0...799
```
因此`y[0]`对应输入`x[0]`的名义时间位置，`y[799]`对应输入`x[3196]`。184个输入采样点的群延迟在模块内部补偿，不能修改`end_generate_timestamp_ns`。本流程不使用`filtfilt`，也不对同一滤波器执行两次正反向滤波。

### 3. `DownsampledPacket`和结果检查
`DownsampledPacket`保留原包身份字段和`end_generate_timestamp_ns`，并包含：
| 数据 | 输出规格 |
|---|---|
| 三路高频信号 | 16000 Hz、800点，单位保持不变 |
| 三路工况序列 | 4000 Hz、200点，数值和顺序保持不变 |
| 温度 | 原值保持不变 |

降采样模块只检查自身输出：
- 三路高频输出均为16000 Hz、800点且全部为有限数值；
- 三路输出使用相同抽取相位并保持位置对应；
- 50 ms窗口、身份字段和`end_generate_timestamp_ns`不变；
- 工况序列和温度未被修改。

任一检查失败，返回`DOWNSAMPLING_FAILED`，不使用上游严格校验错误码。
## 四、感知预处理和质量判断
### 1. 预处理顺序
感知模块只接收完整且已检查通过的`DownsampledPacket`。三路16 kHz信号按以下顺序处理：
```text
16 kHz降采样结果
├── 去直流前 → 恒定波形判断
└── 去直流后
    ├── 不加窗 → 振动和电流时域特征
    └── 周期型Hann窗 → 振动频域特征
```

当前阶段未取得停机噪声RMS，因此不执行`NEAR_ZERO_SIGNAL`质量判断。当前阶段也未取得传感器或采集接口的权威上下边界，因此不执行`POSSIBLE_CLIPPING`质量判断。去直流操作仍然保留，用于后续时域和频域特征计算。

去直流定义为：

```text
x_dc[n] = x[n] - mean(x)
```
振动频域分析使用800点周期型Hann窗：

```text
w[n] = 0.5 - 0.5 × cos(2πn/N)
N = 800, 0 <= n < N
```
Hann窗不能用于时域特征和电流关系特征。
### 2. 单边功率谱密度
振动频谱固定采用：

```text
Fs = 16000 Hz
NFFT = 800
频率间隔 = 20 Hz
X[k] = rFFT(x_dc[n] × w[n])
PSD[k] = |X[k]|² / (Fs × sum(w[n]²))
```

单边谱中DC和Nyquist频点不乘2，其余正频率点乘2；不进行零填充。振动PSD单位为`(mm/s)²/Hz`。
### 3. 质量规则
质量判断只针对三路16 kHz高频信号，不重复上游严格校验。

```text
进入感知模块后先计算当前包平均转速 current_speed_mean_rpm

当前包平均转速 >= running_speed_threshold_rpm
→ 设备处于运行状态
→ 执行恒定波形质量判断

当前包平均转速 < running_speed_threshold_rpm
→ 设备不处于确认运行状态
→ perception_quality.status = warning
→ flags 加入 DEVICE_NOT_RUNNING
→ 不执行 CONSTANT_SIGNAL 判断
→ 仍然尝试计算特征
```

`running_speed_threshold_rpm`是直接配置的运行状态判断阈值，不根据设备额定转速计算。该阈值可以根据数据发送器提供的正常健康运行数据确定，但必须保存明确的来源和版本，运行时不得根据当前包动态计算。`current_speed_mean_rpm`在质量阶段只计算一次，后续组装`operating_context.shaft_speed_rpm.mean`时复用同一结果，禁止再次独立计算。运行状态判断本身不直接终止当前包处理；但未运行状态下，如果信号功率不足以稳定生成必要特征，仍然返回`PERCEPTION_FAILED`。

| 质量问题 | 判断数据 | 规则 | 判断条件 | 处理 |
|---|---|---|---|---|
| 设备未运行 | 当前包平均转速 | 低于显式配置的`running_speed_threshold_rpm` | 始终判断 | `warning`并继续，跳过恒定判断，标志为`DEVICE_NOT_RUNNING` |
| 恒定波形 | 16 kHz去直流前信号 | 峰峰值不超过显式配置的`constant_threshold` | 设备处于运行状态 | `warning`并继续 |
| 接近零波形 | — | 当前阶段不启用 | 缺少可信停机噪声基线 | 不判断、不产生标志 |
| 疑似削顶 | — | 当前阶段不启用 | 缺少权威量程边界 | 不判断、不产生标志 |

未启用`NEAR_ZERO_SIGNAL`不能解释为已经确认信号不接近零；未启用`POSSIBLE_CLIPPING`也不能解释为已经确认信号没有削顶。这两项只是当前阶段不具备可靠判断条件，不影响其他特征继续生成。

当前阶段启用的固定质量标志为：
| 级别 | 标志 |
|---|---|
| 设备级 | `DEVICE_NOT_RUNNING` |
| 通道级 | `VIBRATION_CONSTANT_SIGNAL`、`PHASE_CURRENT_1_CONSTANT_SIGNAL`、`PHASE_CURRENT_2_CONSTANT_SIGNAL` |

`NEAR_ZERO_SIGNAL`和`POSSIBLE_CLIPPING`保留为后续扩展枚举，但当前阶段的感知模块不生成这两类标志。
### 4. 阈值和处理分支

当前阶段不根据硬量程、设备额定转速或停机噪声RMS计算质量阈值。每个高频通道分别显式配置：

```text
constant_threshold
```

恒定判断规则为（仅设备处于运行状态时执行；未运行时跳过，改由`DEVICE_NOT_RUNNING`表达）：

```text
peak_to_peak <= constant_threshold
→ 产生对应通道的CONSTANT_SIGNAL标志
```

`constant_threshold`可以根据正常健康运行数据或人工验证结果确定，但必须保存明确数值、来源和版本，运行时不得根据当前包动态计算。无法得到可信阈值时，对应通道不得启用恒定判断，也不得静默使用零值或临时默认值。

特征计算另外使用独立配置的数值稳定阈值：

```text
feature_zero_rms_threshold
feature_zero_power_threshold = feature_zero_rms_threshold²
current_relationship_zero_rms_threshold
```

`feature_zero_rms_threshold`和`feature_zero_power_threshold`用于防止除零、NaN、Inf以及极小数值被异常放大，不属于传感器质量范围。`current_relationship_zero_rms_threshold`只用于电流关系特征的近零分母保护。这些阈值可以根据数值精度、健康参考数据和人工构造的零信号测试确定，但必须作为显式配置固化，不得依赖停机噪声RMS或硬量程动态计算。

质量状态汇总规则：

```text
设备未运行 → status = warning, flags = [DEVICE_NOT_RUNNING]，不执行恒定判断
设备运行且恒定判断无标志 → status = good, flags = []
设备运行且恒定判断产生标志 → status = warning, flags = 对应的CONSTANT_SIGNAL标志列表
```

未启用的`NEAR_ZERO_SIGNAL`和`POSSIBLE_CLIPPING`不参与质量状态汇总。

`warning`（包括`DEVICE_NOT_RUNNING`）仍然必须生成全部特征。如果振动二阶矩或非直流功率达到特征计算零阈值，必要特征无法稳定计算，则返回`PERCEPTION_FAILED`，不能返回部分结果；此时感知日志的`scope`记录为`INSUFFICIENT_SIGNAL_POWER`。

## 五、特征计算定义

所有时域特征使用去直流、未加窗的16 kHz信号；振动频域特征使用Hann加窗信号。除特别说明外，`N = 800`。

### 1. 振动特征

```text
rms = sqrt(sum(v[n]²) / N)
absolute_peak = max(abs(v[n]))

m2 = sum(v[n]²) / N

如果m2 <= feature_zero_power_threshold
→ 返回PERCEPTION_FAILED
→ 不计算m4和kurtosis

m4 = sum(v[n]⁴) / N
kurtosis = m4 / (m2 × m2)

检查kurtosis为有限数值
```

峭度采用Pearson定义，正常高斯波形接近3。中间累计（m2、m4、时域RMS等）至少使用`float64`，避免`float32`下溢或溢出。

频域特征定义为：

```text
dominant_frequency_hz
= 非直流PSD最大频点的频率；并列时取较低频率

band_power_ratio_500_2000
= 500～2000 Hz PSD积分 / 非直流总PSD积分

P_non_dc = sum(PSD[k]), k = 1...400

如果P_non_dc <= feature_zero_power_threshold
→ 返回PERCEPTION_FAILED

p[k] = PSD[k] / P_non_dc, k = 1...400
M = 400

spectral_entropy
= -sum(p[k] × ln(p[k]), k = 1...400) / ln(400)
```

800点实数FFT产生401个单边频点（k = 0...400），排除DC、包含Nyquist后为k = 1...400，`M = 400`。频带能量占比包含500 Hz和2000 Hz端点。`p[k] = 0`的项按0处理。

振动对象同时输出：

```text
source_sample_rate_hz = 64000
analysis_sample_rate_hz = 16000
unit = mm/s
```

### 2. 电流特征

两路电流分别计算：

```text
rms_a = sqrt(sum(i[n]²) / N)
absolute_peak_a = max(abs(i[n]))
```

每路电流同时输出：

```text
source_sample_rate_hz = 64000
analysis_sample_rate_hz = 16000
unit = A
```

两路电流关系定义为：

```text
current_imbalance_ratio
= abs(rms_1 - rms_2) / ((rms_1 + rms_2) / 2)
```

先计算：

```text
current_mean_rms = (rms_1 + rms_2) / 2
```

如果`current_mean_rms <= current_relationship_zero_rms_threshold`，规定`current_imbalance_ratio = 0`。该分支只用于避免电流不平衡率的分母接近零，不产生`NEAR_ZERO_SIGNAL`质量标志。否则按原公式计算，并检查结果为有限数值。任一路电流特征失败时，不生成关系特征。

### 3. 工况特征

转速、转矩和径向载荷分别使用当前包200点序列计算：

```text
mean = sum(x[n]) / 200
last = x[199]
minimum = min(x)
maximum = max(x)
standard_deviation
= sqrt(sum((x[n] - mean)²) / 200)
```

`shaft_speed_rpm.mean`复用质量阶段计算并保存的`current_speed_mean_rpm`，禁止再次独立计算，避免实现产生细微差异。标准差采用总体标准差。三个工况对象不增加`unit`字段；温度原值写入`operating_context.bearing_module_temperature_c`。

### 4. 特征完整性

组装输出前必须确认：

- 接口要求的全部特征字段已经生成且数值有限；
- 主频位于20～8000 Hz（主频搜索排除DC，且非直流功率已通过零功率守卫）；
- 频带能量占比和频谱熵位于0～1；
- 两路电流RMS由当前`DownsampledPacket`中的两路800点数组计算，不使用缓存值或上一包结果；
- 工况统计只使用当前包的200点序列；
- 不使用默认值或上一包结果补齐失败特征。

## 六、组装`PerceptionResult`

### 1. 输出结构

顶层字段固定为：

```text
task_id
packet_id
sender_id
sequence_number
end_generate_timestamp_ns
feature_generated_at_ns
perception_quality
features
```

`features`固定包含：

```text
features
├── vibration
├── phase_current_1
├── phase_current_2
├── current_relationship
└── operating_context
    ├── shaft_speed_rpm
    ├── load_torque_nm
    ├── bearing_radial_load_n
    └── bearing_module_temperature_c
```

输入通道`phase_current_1_A`和`phase_current_2_A`分别映射到`phase_current_1`和`phase_current_2`。

输出不得包含原始或降采样`values`数组、`raw_packet_ref`、`perception_received_at_ns`、`edge_node_id`、原始上下文、模型输出、置信度、风险等级和特征提取版本字段。

### 2. 输出检查和时间戳顺序

先组装不含`feature_generated_at_ns`的`PerceptionResultDraft`，检查：

- 身份和采样时间字段与输入一致；
- `perception_quality.status`为`good`或`warning`，`flags`为列表；
- 全部特征字段存在且数值有限；
- 输出中不存在禁止字段。

检查通过后按以下顺序完成输出：

```text
读取统一时钟一次
→ 写入feature_generated_at_ns
→ 组装最终PerceptionResult
→ 检查时间戳类型和顶层结构
→ 返回任务编排器
```

失败时不对外输出`feature_generated_at_ns`。

### 3. 时间戳含义

全系统只使用一个Unix纳秒时钟，时间戳保存为64位整数：

| 时间戳 | 含义和产生时机 |
|---|---|
| `end_generate_timestamp_ns` | 发送器在当前包采样完成时生成，本模块原样传递 |
| `perception_received_at_ns` | 任务编排器准备调用降采样模块前读取统一时钟生成，覆盖降采样、感知预处理和特征计算，不含严格校验和原始缓存写入；通过`PerceptionInvocationContext`传入本模块 |
| `feature_generated_at_ns` | 输出草案通过检查后生成，并写入成功结果 |
| `log_generated_at_ns` | 错误日志对象生成时生成 |

感知处理总耗时可以按`feature_generated_at_ns - perception_received_at_ns`计算。

`PerceptionInvocationContext`由任务编排器在调用降采样模块前生成，至少包含`edge_node_id`和`perception_received_at_ns`。`perception_received_at_ns`不进入`PerceptionResult`，只用于日志、内部耗时统计和监控指标。

## 七、失败、日志和数据所有权

| 错误码 | 使用范围 |
|---|---|
| `DOWNSAMPLING_FAILED` | 抗混叠、抽取或`DownsampledPacket`检查失败 |
| `PERCEPTION_FAILED` | 预处理、特征计算或`PerceptionResult`组装检查失败 |

失败时返回`success = false`、对应`error_code`和`payload = null`，不得以0、空对象或上一包结果替代失败特征。

本地错误日志至少记录：

```text
task_id、packet_id、sender_id、edge_node_id
perception_received_at_ns、log_generated_at_ns
stage、scope、error_code
expected、actual、action = processing_stopped
```

其中`stage`为`downsampling`或`perception`；`edge_node_id`来自`PerceptionInvocationContext`。感知阶段因信号功率不足返回`PERCEPTION_FAILED`时，`scope`记录为`INSUFFICIENT_SIGNAL_POWER`。日志不得保存完整波形数组。

降采样和感知只能修改独立计算副本。无论成功或失败，都不得修改环形缓存中的`ValidatedRawPacket`、`raw_packet_ref`和`ContextSlot`。失败包的原始数据继续按照缓存保留规则保存。

## 八、配置和启动检查

以下配置必须统一管理，不能散落在代码中：

- 固化的FIR系数、采样率、抽取倍数、边界规则和抽取相位；
- Hann窗、NFFT和PSD标度；
- 每个高频通道的`constant_detection_enabled`、`constant_threshold`及其来源和版本；
- `running_speed_threshold_rpm`及其来源和版本；
- `feature_zero_rms_threshold`和`feature_zero_power_threshold`；
- `current_relationship_zero_rms_threshold`；
- 当前启用的质量规则集合；
- 降采样和感知错误码。

启动时至少检查：

1. 三路高频信号使用同一组369系数，并满足对称性、直流增益和频率响应要求；
2. 64 kHz到16 kHz的抽取倍数为4，边界规则和抽取相位完整；
3. `running_speed_threshold_rpm`为有限非负数，且来源和版本完整；
4. 启用恒定判断（`constant_detection_enabled = true`）的高频通道均已配置合法的`constant_threshold`，且来源和版本完整；
5. `feature_zero_rms_threshold`和`feature_zero_power_threshold`为有限正数，并满足约定的平方关系；
6. `current_relationship_zero_rms_threshold`为有限非负数；
7. `NEAR_ZERO_SIGNAL`和`POSSIBLE_CLIPPING`当前处于禁用状态；`DEVICE_NOT_RUNNING`作为设备级标志随运行状态判断启用；
8. Hann窗、NFFT、单边PSD和20 Hz频率间隔符合本文定义；
9. 感知模块能够生成接口要求的全部字段；
10. 所有时间字段使用同一个Unix纳秒时钟。

启用恒定判断但缺少对应阈值时，禁止启用该通道的恒定判断；数值稳定阈值缺失或互相冲突时，停止启动感知处理流程。`NEAR_ZERO_SIGNAL`或`POSSIBLE_CLIPPING`未启用不阻止启动，但必须在启动日志中记录当前质量判断能力。不得静默使用临时默认值启动任何已启用的规则。

## 九、最小验收标准

| 验收内容 | 通过条件 |
|---|---|
| 正常降采样 | 三路均输出16 kHz、800点，并保持同一50 ms窗口 |
| 滤波器响应 | 实际系数满足通带波动不大于0.1 dB、8000 Hz以上衰减不小于80 dB |
| 零相位对齐 | 脉冲和三路同步测试证明首样本、抽取相位和时间字段不偏移 |
| 数据保持 | 工况序列、温度、身份字段和`end_generate_timestamp_ns`不变 |
| 运行状态判断 | 根据显式配置的`running_speed_threshold_rpm`判断，不使用设备额定转速 |
| 未运行处理 | 平均转速低于阈值时产生`DEVICE_NOT_RUNNING`并跳过恒定判断；信号功率足够时仍生成完整特征 |
| 未运行零功率 | 未运行且振动功率不足时返回`PERCEPTION_FAILED`，不静默返回`good` |
| 恒定判断 | 运行状态下，峰峰值不超过显式阈值时产生对应的`CONSTANT_SIGNAL`标志 |
| 未启用规则 | 当前阶段不产生`NEAR_ZERO_SIGNAL`和`POSSIBLE_CLIPPING`标志 |
| 质量分支 | `warning`仍生成完整特征；达到特征计算零阈值时返回`PERCEPTION_FAILED` |
| 振动零功率 | 全零或极小振动不产生除零、NaN或Inf，而是返回`PERCEPTION_FAILED` |
| 电流关系零分母 | 两路电流平均RMS不超过数值稳定阈值时，`current_imbalance_ratio`固定为0 |
| 特征正确性 | 已知输入下的时域、频域、电流关系和工况特征符合本文定义 |
| 输出接口 | 字段完整、数值有限，不包含波形数组、模型字段和特征提取版本字段 |
| 时间顺序 | 草案检查通过后才生成`feature_generated_at_ns`，失败结果不承载该字段 |
| 失败隔离 | 当前包失败不进入后续阶段，也不影响其他数据包 |
| 缓存不变 | 处理前后缓存中的原始包逐字段和逐数组一致 |

满足以上条件后，任务编排器可以把完整`PerceptionResult`交给边缘模型。
